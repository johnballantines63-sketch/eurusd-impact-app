## 🔑 FORMULES RÉFÉRENCE

### Score Tendance V2 (Session 92.13)

```python
def calculate_score_v2(trend, duration_hours, r_squared, amplitude_pips):
    """
    Score tendance avec amplitude
    
    Paramètres calibrés Session 92.13 :
    - amplitude_method : 2 (plafonné)
    """
    # Direction
    if trend == "HAUSSIER":
        direction = +1.0
    elif trend == "BAISSIER":
        direction = -1.0
    else:
        direction = 0.0
    
    # Normalisation durée
    duration_normalized = min(duration_hours, 24.0) / 24.0
    
    # Amplitude factor (plafonné)
    amplitude_factor = min(abs(amplitude_pips) / 100.0, 1.0)
    amplitude_factor = max(amplitude_factor, 0.1)
    
    # Score final
    score_v2 = direction * duration_normalized * r_squared * amplitude_factor
    
    return score_v2
```
