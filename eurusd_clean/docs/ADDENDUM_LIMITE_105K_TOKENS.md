## 🎯 LIMITE TOKENS PROJET : 105,000 MAX

### Contexte

Le budget technique Claude est 190,000 tokens, **MAIS** la limite PROJET est fixée à **105,000 tokens maximum** pour garantir qualité documentation finale.

### Rationale

**Raisons limite 105k :**
1. **Qualité documentation** : 10-15k tokens nécessaires pour rapports complets
2. **Message transition** : 5k tokens pour session suivante
3. **Buffer sécurité** : Éviter précipitation fin de session
4. **Efficacité** : Forcer concision et pertinence

### Budget Type Session Productive

```
Documentation lecture :      30-40k tokens
Validation utilisateur :     5-10k tokens
Implémentation ciblée :      30-40k tokens
Tests validation :           10-15k tokens
Documentation finale :       10-15k tokens
────────────────────────────────────────
Total session réussie :      85-105k tokens
```

### Règles Monitoring

**À chaque session :**
- ✅ Afficher tokens tous les 20k
- ✅ Dire explicitement : "Tokens : X / 190,000 (Limite projet : 105k)"
- ⚠️ À 90k tokens → Alerter approche limite
- 🛑 À 100k tokens → Préparer finalisation immédiate
- 🚨 À 105k tokens → STOP et rapports finaux uniquement

### Checkpoints Critiques

**80k tokens :** Évaluer avancement
- On track ? Continuer
- Retard ? Prioriser essentiel

**90k tokens :** Phase finale
- Compléter implémentation en cours
- Pas de nouveaux développements

**100k tokens :** Documentation
- Rapports finaux uniquement
- Message transition
- Mise à jour project_state_new.md

**105k tokens :** FIN SESSION
- Aucun développement supplémentaire
- Session suivante si nécessaire
