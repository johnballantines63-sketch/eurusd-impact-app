## 📐 FORMULES UTILISÉES

### Amplification idéale
```
amp_ideal = impact_real / (score_total × sqrt(n_events))
```

### Prédiction impact
```
impact_predicted = score_total × amp × sqrt(n_events)
```

### R² tendance
```
R² = coefficient détermination régression linéaire (7 jours avant événement)
```

## 📝 NOTES

- **Amp idéale** : Valeur qui prédit exactement l'impact du cas référence
- **Score total** : Somme scores empiriques événements cluster
- **N events** : Nombre événements avec score disponible
- **R² tendance** : Mesure force tendance pré-événement (0=aucune, 1=parfaite)
- **Statut validé** : Cas testé et validé session précédente (ex: 11 sept S115)
